# CD Companion — Android App

Segunda tela para o [CD Companion](https://github.com/leandrodiogenes/cd-companion), mod para Crimson Desert que exibe sua posição em tempo real no mapa do MapGenie.

Este repositório contém apenas os releases do APK Android.

---

## O que o app faz

- Abre o mapa do MapGenie em tela cheia no seu celular ou tablet
- Exibe o marcador de posição do jogador em tempo real
- Conecta ao servidor do CD Companion na sua rede local via WebSocket
- Funciona como segunda tela — o PC roda o companion normalmente

---

## Requisitos

- Android 8.0 (Oreo) ou superior
- CD Companion rodando no PC na mesma rede Wi-Fi
- [CD Companion para PC](https://www.nexusmods.com/crimsondesert/mods/2125)

---

## Instalação

1. Baixe o APK da [release mais recente](../../releases/latest)
2. No Android, habilite **"Instalar apps de fontes desconhecidas"** para o seu gerenciador de arquivos
3. Abra o APK baixado e instale
4. Abra o app e vá em **⋮ > Configurações** para definir o IP do PC

---

## Configuração

No menu do app (três pontos no canto superior direito):

- **Configurações** — define o IP e a porta do PC onde o CD Companion está rodando
  - IP padrão: `10.0.0.9`
  - Porta padrão: `7891`

O app verifica atualizações automaticamente ao abrir e avisa quando há uma nova versão disponível.
